# Changelog

## [v1.0.0] - 2026-10-08

Initial release (no prior history).

### Added
- Raw Input listener for keyboard, mouse, gamepad, consumer-control and vendor HID devices.
- Per-event log line with the Bluetooth address parsed from the HID device path, plus VID/PID.
- Key names for keyboard events, raw bytes for other HID reports, throttled mouse movement.
- `Run.bat` launcher and a Clear button.
